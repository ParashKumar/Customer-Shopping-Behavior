# Customer-Shopping-Behavior
Customer shopping behavior data analytics project using python, MySQl and PowerBI.


## Overview

This project demonstrates an end-to-end **data analysis workflow** using Python, MySQL, and Power BI.

The project covers data loading, exploratory data analysis (EDA), data cleaning, SQL-based analysis, and dashboard development to extract meaningful insights from the dataset.

## Dataset

The dataset contains structured information that is analyzed to identify patterns, trends, and key business insights.

**Dataset format:** CSV

## Tools & Technologies

* **Python** — Data loading, cleaning, and EDA
* **Pandas** — Data manipulation and analysis
* **MySQL** — SQL queries and data analysis
* **Power BI** — Interactive dashboard and visualization
* **Jupyter Notebook** — Python-based analysis

## Project Steps

### 1. Load Dataset

* Imported the dataset into Python using Pandas.
* Reviewed the dataset structure, columns, and data types.

### 2. Exploratory Data Analysis (EDA)

* Analyzed dataset dimensions and summary statistics.
* Identified patterns and trends.
* Examined missing values, duplicates, and unusual data points.
* Created visualizations to understand the data.

### 3. Data Cleaning

* Handled missing values.
* Removed duplicate records.
* Corrected data types and inconsistent values.
* Prepared the dataset for further analysis.

### 4. SQL Analysis

* Imported the cleaned dataset into MySQL.
* Extracted key metrics and insights from the data.

### 5. Power BI Dashboard

* Connected the cleaned data to Power BI.
* Created charts, slicers, and interactive visuals.
* Designed a dashboard to present the most important findings clearly.
